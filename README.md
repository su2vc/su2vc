## 💡 我的开发理念

**先理解问题，再选择工具。**  
关注实际需求，避免为了使用某项技术而使用它。

**保持简单，持续交付。**  
先完成有价值的核心功能，再根据反馈完善。

**让代码能被接手。**  
清晰的命名、必要的文档和合理的结构，同样是作品的一部分。
